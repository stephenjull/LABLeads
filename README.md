# LABLeads — A Stable Configuration

A living visual model of the LABLeads community of practice. Atoms = creators (lab leads at the core, active creators in shell, listeners in orbit). Bonds = real conversations: cohort ties, collaborations, and intros.

Built as a single self-contained `index.html`. To publish:

1. Push this folder to a new GitHub repo.
2. **Settings → Pages →** deploy from `main` branch / root.
3. Open the published URL — the visualization is live.

## Editing

Everything lives in `index.html`. The visual model, palettes (`PALETTES`), quote library (`QUOTES`), and tag set (`TAGS`) are at the top of the `<script>` block — edit those to evolve the model as you collect more insights.

## Tweaks

A live control panel (top-right gear) lets you adjust population, orbit speed, pulse rate, layout (orbital / regional / free), bond visibility, quote callouts, and palette (Lab cream / Dusk / Midnight).
